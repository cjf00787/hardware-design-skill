# 芯片手册（Datasheet）获取与验证流程

阶段 2 使用。目标：**每一个写进设计的参数都能追溯到手册页码**。

## 1. 手册来源优先级

1. **原厂官网 PDF**（最优）：型号搜索 → 官网 Documents/Product 页。注意认准原厂域名（如 ti.com、wch.cn、st.com）。
2. **授权分销商商品页附件**：立创商城（szlcsc.com）商品页的"资料下载"一般可达原厂 PDF，且能确认购买渠道对应的厂商——**同型号不同厂以实际购买渠道的手册为准**。
3. 国际渠道：LCSC / DigiKey / Mouser 商品页 datasheet 链接。
4. 可信镜像与开发板原理图（仅作旁证）。

**警惕**：dzsc、维库等中文资料站存在大量 AI 生成的"规格书"页面，参数经常错标（耐压、电流、封装张冠李戴）。它们只能当**检索线索**（比如发现"这个型号存在"），**任何写进设计的参数必须落在原厂 PDF 上**。

## 2. 下载与命名

- 存放：`datasheets/`（或用户指定的目录）。
- 命名：`型号_厂商_版本.pdf`（例：`MP1584EN_MPS_DS.pdf`、`CH32X035G8U6_WCH_DS_V1.7.pdf`）。
- 克隆料/国产替代**必须**拿实际厂商的手册：引脚兼容 ≠ 参数兼容（开关频率、补偿方式、基准电压都可能不同）。原厂手册不能替代替代料手册。
- 网络受限时的替代路径：分销商在线预览、原厂中国站点、搜索引擎缓存。下载失败的型号列入"待确认"并告知用户。

## 3. 关键页读法（按顺序）

| 章节 | 提取什么 | 常见坑 |
| --- | --- | --- |
| Absolute Maximum Ratings | 每个引脚的耐压上限、ESD | **绝对最大 ≠ 推荐工作**；短期不坏 ≠ 能用 |
| Recommended Operating Conditions | 电压/电流/温度的可用区间 | 设计点必须落在推荐区间内 |
| Pin Configuration / Pin Description | 逐脚名称与功能；多封装型号引脚号不同 | 只抄当前封装的脚号；注意"仅 XX 封装才有"的功能（如复位脚）；NC 脚与 GND 脚别混 |
| Electrical Characteristics | 典型/最差值；基准电压、RDS(on)（注意对应 VGS 条件）、静态电流 | 典型值适合估算，裕量计算用最差值 |
| Typical Application | 外围电路取值 | 照抄参考电路也要标注"参考电路 p.xx"，并核对与本设计条件（电压域、频率）是否一致 |
| Package / Ordering Information | 封装后缀含义、温度等级、包装 | 后缀不同可能是不同flash/温度/封装 |

## 4. 结论 → 页码 记录格式

读手册的产出是"核对结论表"，随选型表一起给用户：

```markdown
| 器件 | 核对项 | 结论 | 依据 |
| --- | --- | --- | --- |
| U2 | FB 基准 | 0.8V | 《MP1584EN》p.12 §7.3.1 |
| U2 | 开关频率 | 100~220kHz（RT=240k→173kHz） | 《MP1584EN》p.5 公式 |
| D3 | 额定电流 | 5A @ 60V | 《SS56_XX厂》p.1 |
```

设计文档中的引用格式：`VOUT = 0.8×(1+100k/32k) = 3.30V（《MP1584EN》p.12）`。
查不到的项写 `待确认`，不许空着也不许猜。

## 5. 引脚核对流程（写文档前的强制关卡）

EDA 库符号引脚可能与手册不同（嘉立创 EDA 在线库由社区维护，偶有错误；其他 EDA 库同样要核）：

1. 从手册 Pin Configuration 抄出**当前封装**的完整引脚表（脚号 → 名称 → 功能）。
2. 请用户截图 EDA 库的引脚图/符号（嘉立创 EDA：编辑符号界面截图即可），或导出符号定义文本。**截图需要具备视觉能力的模型**：无视觉能力时改用文本替代——商城商品页的引脚表可直接复制文本、多数 EDA 支持导出符号定义文本、或请用户把关键引脚抄成文字，不要假装看图。
3. 逐脚对照，产出对照表：`脚号 | 手册 | EDA库 | 一致?`。
4. 不一致以**手册**为准：提醒用户在 EDA 里修库或换库；修完再继续。
5. 特别注意：
   - 多封装系列里"某功能仅 XX 封装才有"（如复位脚只在部分封装存在）
   - 内部短接/仅输入的引脚（手册 Notes 里常写"pin X 与 pin Y 内部相连"）
   - 电源脚与散热焊盘（EP）——EP 通常必须接地，别漏

## 6. 与设计文档的闭环

- 引脚核对表、参数核对表作为阶段 2 → 阶段 3 的交接物保留在 `docs/specs/`（或对话记录中明确引用）。
- 阶段 3 写文档时，每个 IC 的引脚号**只允许**来自核对过的引脚表，不允许凭记忆补。
