# SVG 拓扑图绘制规范

阶段 3 画图时使用。拓扑图不是原理图：画的是**结构关系**（谁连谁、信号流向、关键器件），不是引脚级完整连线——引脚级细节由文档表格承载。

| 图 | 位置 | 内容 |

| 系统架构图 | §1.1 | 功率链（左→右）、辅助供电分支、主控与各模块的控制/反馈关系 |
| 模块拓扑图 | §2.x 每模块 | 核心器件 + 外围元件（位号+参数）+ 网络名；IC 引脚用文字标注 |
| 叠层/阻抗图 | §3.1/3.3 | 叠层剖面（各层铜厚/介质/厚度/Dk）+ 差分线几何（W/S/H） |
| 布局分区图 | §3.4 | 板框 + 功能分区方框（ASCII 或 SVG 均可，SVG 更佳） |

## 2. 风格规范（浅色主题）

配色语义固定，全图一致：

| 元素 | 填充 | 描边 | 用途 |
| --- | --- | --- | --- |
| 功能电路框 | #EBF3FB | #3E7BC4 | 芯片/电路块；主控可加深一档 #DDEBFA/#2F6FBA |
| 接口/连接器框 | #F6F0E4 | #C9A26B | 母座、排针、按键、外接模块 |
| 输出框 | #E9F6EB | #4C9E5F | 输出端子/最终结果 |
| 无源器件框 | #F7F8FA | #8A94A6 | 阻容感/二极管小盒（两行：位号加粗 + 参数） |
| 网络胶囊 pill | 按 net 类型 | — | VBUS #FDF0E7/#C0562A；3V3 #FDE8E8/#C0392B；信号 #E8F1FB/#3E7BC4 |

| 次要线 | — | #8A8F98，粗 1.5 | 开尔文、ADC 等辅助 |

文字字体：`font-family="Microsoft YaHei, PingFang SC, Noto Sans CJK SC, sans-serif"`。标题 13~16px 加粗，副文/标签 10.5~12px。

## 3. 结构元件画法

- **节点框**：`<rect rx="10">` + 居中两三行文字（`text-anchor="middle"`）。
- **网络胶囊 pill**：`<rect rx="13" width≈60~90 height=26>`，内写网络名；用 pill 断开长连线——"这条线通向网络 X"由同名 pill 表达，**不要跨全图画长线**。
- **GND 符号**：竖线 8px + 三横（14/9/4px 递减），灰色 #6B7280，粗 1.6。
- **箭头 marker**：`markerUnits="userSpaceOnUse"`（防止随线宽缩放），`markerWidth=9 refX=8 orient=auto`，每种颜色定义一个 marker。
- **画布**：宽 900~1060px，高按内容；**必须**加 `<rect width="100%" height="100%" fill="#FFFFFF"/>` 白底，否则暗色主题下不可读。

## 4. 布局纪律（防翻车）

- **连线不交叉**：优先用 pill 断网；必须画线时按"横平竖直 + 提前规划出口位置"排布，一个交叉都嫌多。
- **文字宽度预估算**：中文每字 ≈ 字号 px；英文数字 ≈ 0.6×字号。放不进框就缩字号或加宽框，不允许溢出。
- **框间距 ≥16px**，标签与线错开 ≥10px，避免文字压线。
- 图内不写价格、不写待办；位号与文档表格严格一致（图是表格的镜像）。
- 复杂模块拆多列分区（如电源模块分"输入侧/输出侧/反馈网络"三个 zone），zone 之间留白 ≥40px。
- 画完用浏览器/预览打开自查一遍：文字溢出、连线穿框、箭头方向反了，都是常见病。

## 5. 尺寸参考

- 系统架构图：约 1060×650，横向功率链 7~8 个节点，中部主控大框，底部人机接口一行。
- 模块拓扑图：约 940~1000×500~740，中心 IC 框 + 四周分区。
- 叠层图：左右分栏，左侧剖面（铜层 10~16px、介质按比例 40~120px），右侧几何示意 + 公式 + 结论框。
- 布局图：与板框比例接近即可，不必精确。
