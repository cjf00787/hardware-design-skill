# 选型指标与核算规范

阶段 2 出《选型指标表》、阶段 3 写"表下选型计算"时使用。原则：**先指标后型号**；每条结论带依据（手册页码 / 计算 / 实测）。

## 1. 出《选型指标表》的方法

对方案里每类元件回答四个问题，产出 `类别 | 指标要求 | 依据` 三列表：

| 维度 | 要列什么 | 注意 |
| --- | --- | --- |
| 耐压 | 最高**工作**电压（含源端容差，通常 +5%） | 不是额定值，是应力值 |
| 耐流 | 连续值 + 峰值/浪涌值 | 峰值决定很多选型 |
| 精度 | 从最终输出/显示精度**倒推**分配到每级 | 例：显示 0.01A → 采样链综合 ≤±1% |
| 封装 | 由功耗（热阻）、电流（端子额定）、工艺（手焊可达性）决定 | 大电流先看端子再看芯片 |

## 2. 耐压裕量惯例

| 器件 | 惯例 | 说明与示例 |
| --- | --- | --- |
| TVS | 截止电压（V_RWM）> 最高工作电压（TVS 不导通）；**钳位电压 vs 后级耐压必须写"边界声明"** | 工作 21V → 取 V_RWM=22V 档；若钳位 35.5V > 后级 MOS 30V，必须声明"浪涌超钳位值时后级可能超压，学习板接受/换 40V 管" |
| 电容 | 耐压 ≥1.2× 最高工作电压；X5R/X7R 按**有效容量**复核——直流偏压下实际容量可能只剩标称 30~60% | 工作 21V（含 +5% = 22V）→ 取 25V；DC-DC 输入电容还要满足协议电容预算 |
| MOS | VDS ≥1.3× 最高工作电压 + TVS 钳位边界声明；**RDS(on) 取实际 VGS 下的值**，不抄规格点 | VGS=−5V 时 RDS(on) 通常比 −10V 规格点高 30~100%，5V 输入场景必须查曲线 |
| 二极管 | 反向耐压 ≥1.5× 反向应力；正向按平均 + 峰值；开关应用**反向恢复时间 < 开关周期/10** | 工频整流管（1N4007，trr 2~30µs）严禁用于 100kHz+ 开关回路 |
| IC | 区分绝对最大额定（Absolute Maximum）与推荐工作条件（Recommended Operating）；某脚耐压与应用矛盾时 → 加钳位稳压管保险 + 在文档记录矛盾 | 例：EN 经 100k 上拉到高压域，但手册写"All pins 6V"且原厂参考电路自己就这么画 → 判断为手册遗留，加 5.1V 稳压管，钳位电流 = (V源−Vz)/R |
| 稳压管（钳位用） | 工作电流 = (V源−Vz)/R，需 ≥ Izt 且功耗 = Vz×I ≤ 额定×0.5 | |

## 3. 耐流与载流

**走线/过孔**（用 `scripts/trace_current.py` 算，别心算）：

- IPC-2221：`I = k·ΔT^0.44 · A^0.725`，外层 k=0.048、内层 k=0.024，A 单位 mil²（1oz 铜 ≈ 1.37mil 厚，0.5oz ≈ 0.69mil）。
- 速查（1oz 外层、ΔT=10°C）：5A → 2.78mm；3.9A → 2mm；3A → ≈1.4mm。内层减半再打七折。
- 换层过孔 0.3mm 孔径经验值 1.5~2A/孔，用阵列并联；大平面（电源层）单独算。
- IPC-2152 比 2221 更准且更宽松；用 2221 是保守习惯，写文档时注明。

**器件端**：

- 连接器/开关/端子额定 ≥1.5× 连续电流；插拔端子看厂家额定曲线。
- 采样电阻：P = I²R，额定 ≥3×P；**合金比厚膜 TCR 低一个量级**（±75 vs ±300ppm/°C），自热温升 × TCR = 漂移，精度链里必须算这笔。
- 电感：峰值电流 = 平均 + ΔIL/2 < Isat（留 ≥2× 裕量）；ΔIL = (VIN−VOUT)×D/(L×f)，D = VOUT/VIN。
- DC-DC 外围二极管：续流管看平均电流 Iout×(1−D) 与峰值 = 电感峰峰；耐压 > VIN + 裕量。

## 4. 精度链

- **电阻分压**：用 1% 档；分压误差 ≈ 电阻容差直接进结果。分压电流 ≥10× 采样节点漏电流。
- **分压 + ADC**：源阻抗 = R上∥R下；τ = 源阻抗 × 外接滤波电容；**采样时间 ≫ τ**（≥10×，查 MCU 手册的最大外部阻抗表）。分压中点占 ADC 满量程 70~85%，并验算最大输入（含容差）不超过基准电压。
- **电流检测**：满量程压降设计在检测量程的 70~85%（例：±81.92mV 量程用到 65mV）；综合精度 ≈ shunt 精度 + 放大器增益误差 + 温漂项。
- **显示口径**：显示精度以专用测量 IC 为准，MCU 内部 ADC 只做后备——文档里写明"以谁为准"。

## 5. 封装选择

- 默认 0603（手焊/回流都友好），全板统一默认值 + 例外清单写在原理图章节导读（"除特别标注外 0603/50V/X7R，例外：…"）。
- 功率电阻按 P 升 1206/2512；合金采样 1206/2512 优先（四端开尔文封装更好但贵）。
- 小信号稳压管/TVS：SOD-123；整流/续流按电流 SMA/SMB。
- IC 优先带散热 EP 的封装；手工焊避开无延伸脚 QFN、BGA、0402 以下。
- 母座/端子：先看端子额定电流与接触电阻，再看机械（卧贴/立贴/板边距离）。

## 6. 料号与数据陷阱

- **料号解码不能跨品牌**：三星 MLCC 电压代码在倒数第 5 位（`CL10A475KA8NQNC` 的 A = 25V）；村田在倒数第 3 位（1E = 25V、1H = 50V）。拿到料号先查原厂编码规则。
- **同型号不同厂**：SS56 各家 Ir/Vf/封装不同；购买渠道决定以哪家的手册为准。
- 商城网页"参数表"可能漏写关键项（额定电流/功率/TCR）→ 一律与规格书 PDF 交叉核对，**只信 PDF**。
- 克隆料/国产替代：引脚兼容 ≠ 参数兼容（开关频率、COMP 补偿、基准电压都可能不同），必须拿**实际厂商**的手册，不能用原厂手册替代。
- 检索型号"不存在"时：先怀疑自己解码错了 → 换关键词 → 原厂官网 → DigiKey/Farnell 交叉验证。用户手里有实物/截图时优先采信实物。

## 结论记录格式

每条选型结论按此格式写进选型表/设计文档：

```markdown
L1 = 22µH（计算：ΔIL=0.73A、峰值 0.41A < Isat/2；手册《FNR6045S》p.2 Isat=2.2A）
```

即：**结论 +（计算：公式与代入 | 手册：《型号》p.xx | 实测：条件与结果）** 三选一，不许裸结论。
