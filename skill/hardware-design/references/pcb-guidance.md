# PCB 板材 / 叠层 / 阻抗 / 载流 指南

本文件是**方法论 + 通用知识**。各板厂的具体工艺参数（叠层、PP 厚度、介电常数、铜厚、免费打样规格）**不在此固化**——必须按 §1 流程针对用户选择的板厂运行时联网查询。

## 1. 板厂参数查询流程（每次项目都执行）

1. **问用户**：在哪家板厂打样（嘉立创、捷多邦、JLCPCB、PCBWay 等）、板层数、是否用免费/低价打样通道。
2. **联网查该厂当期工艺**：官网"工艺参数/层压结构/阻抗计算"页面。要拿到的参数清单：
   - 叠层结构：每层铜厚（外/内层 oz）、介质类型与厚度（PP 型号与压合厚度）、芯板厚度
   - 各 PP/介质的介电常数 Dk（板厂自己公布的计算值）
   - 阻焊参数（厚度、Dk，影响外层阻抗 2~3Ω）
   - 最小线宽/线距、孔径、阻抗控制公差与是否免费
   - 官方阻抗计算工具入口
3. **记录**：把查到的参数写进项目设计文档 §3.1，逐项注明来源 URL 与查询日期（板厂工艺会更新，过参数等于错参数）。
4. 用查到的参数做载流/阻抗计算（本文 §3/§4 公式，或 `scripts/trace_current.py`、`scripts/impedance_calc.py`）。

## 2. FR-4 基础知识（通用，不随板厂变）

| 参数 | 含义 | 对设计的影响 |
| --- | --- | --- |
| Dk（介电常数） | 材料储电能力，随频率与树脂含量（RC%）变化 | 直接进阻抗公式；Dk 越大同线宽阻抗越低 |
| Df（损耗因子） | 介质损耗 | >5Gbps 才明显 |
| Tg（玻璃化温度） | 树脂软化点 | 无铅回流（峰值 ~260°C）需高 Tg + 低 Z 轴 CTE |
| CTE / Td / T288 | Z 轴膨胀 / 分解温度 / 抗分层时间 | 过孔可靠性；厚板、多次回流关注 |

**板材档位**（原厂 TDS 典型值，引用时注明"以原厂 TDS 为准"）：

| 档位 | 代表型号 | 特点 | 何时用 |
| --- | --- | --- | --- |
| 普通 FR-4 | 各厂标准板 | Tg 130~140°C，Dk≈4.5@1MHz | 双层/低密多层，速率低 |
| 高 Tg 无铅 | 生益 S1000-2 / 联茂 IT-180A | Tg 170~180°C，Dk≈4.2~4.8，Df 0.013~0.017 | 多层板主力、无铅工艺 |
| 低损耗 | 松下 Megtron 6 等 | Dk≈3.7，Df≈0.002 | >5Gbps |
| 高频/PTFE | Rogers RO4350B（Dk 3.48@10GHz）/ RT-duroid | 低损耗、贵 | RF/毫米波 |

**升级判据**：信号边沿 <1ns 或速率 >5Gbps → 低损耗板；RF → 高频板；其余普通 FR-4 足够。玻纤编织效应（Dk 微观不均）>10Gbps 才需关心。

## 3. 载流计算（IPC-2221，保守）

公式：`I = k · ΔT^0.44 · A^0.725`；外层 k=0.048，内层 k=0.024；A 单位 mil²（铜厚：1oz≈1.37mil、0.5oz≈0.69mil）。

- 由电流求线宽：`A = (I / (k·ΔT^0.44))^(1/0.725)`，`W = A / 铜厚mil`（用 `scripts/trace_current.py`）。
- 速查（1oz 外层、ΔT=10°C）：5A → ≈2.8mm；3.9A → 2mm；3A → ≈1.4mm；内层同电流线宽显著加大。
- 换层过孔：0.3mm 孔径经验值 1.5~2A/孔，做 ≥4~6 孔阵列并联；电源平面整体承载另算。
- IPC-2152 更准且更宽松；用 2221 属保守习惯，文档注明即可。
- 平面层载流：整层铜带宽度极大，一般温升可忽略，瓶颈在 L1 引线与过孔——"短粗线 + 平面 + 过孔阵列"三层并联。

## 4. 阻抗计算（微带）

单端微带近似（IPC-2141 系，W/H 在 0.1~2 有效）：

```
Z0    = 87/√(εr+1.41) × ln( 5.98H / (0.8W+T) )
Zdiff = 2·Z0 × ( 1 − 0.48·e^(−0.96·S/H) )      （边缘耦合差分）
```

- H = 走线层到参考平面的介质厚度（用板厂查询到的压合厚度），εr 用板厂公布的 Dk，T = 铜厚（含电镀）。
- 计算值是**估算**：阻焊会拉低 2~3Ω，板厂公差 ±10%。文档写法：给设计值 + 注明"下单前用板厂阻抗工具复核"（绝大多数板厂有免费阻抗计算器/下单阻抗选项）。
- 常见目标：USB 2.0 差分 90Ω±10%；单端 50Ω 备查。低速信号（I2C/UART/CC 的 BMC）**不做阻抗控制**，只要求短、参考地完整。

## 5. 布局方法

- 功率路径一条直线贯穿（输入端子 → 处理 → 输出端子），不绕行不分支；端子全部靠板边。
- 人机接口（按键/显示）远离功率区；敏感模拟（采样、开尔文走线）贴着各自 IC。
- 去耦电容贴电源脚；晶振/时钟贴 IC 且下方不走线；发热件留铺铜。
- 开关电源：输入电容–芯片–续流管–电感环路面积最小；SW 节点铜面积适中不铺大铜。
- 布局分区用 ASCII 或 SVG 画进文档（方框图即可）。

## 6. 布线规则表模板

| 网络 | 规则 | 原因 |
| --- | --- | --- |
| 大电流路径 | 线宽按 §3 计算 + 平面并联 + 过孔阵列 | 载流与温升 |
| GND | 完整参考平面，不分割；换层就近打地孔 | 参考完整性 |
| 差分对（如有） | 按 §4 设计值，并行等长，下方完整地 | 阻抗 |
| 敏感模拟 | 短、远离功率、独立引出（开尔文） | 毫伏级精度 |
| 开关节点 | 环路最小、铜面适中 | EMI |
| 慢速数字 | 普通走线即可 | 无阻抗需求 |

## 7. 间距 / 丝印 / 测试点（文档 §3.6 常用项）

- 间距按板厂最小值与电压等级（SELV 低压通常 0.2mm 起步）；端子按封装。
- 丝印：危险/易错处必标（极性、电压档位、刷机方法、最大电流）。
- 测试点：电源轨、关键信号（总线、使能）各留 1~2mm 孔距测试点。
